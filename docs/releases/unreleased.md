# Project Unreleased

capability. No executable package, database schema, CLI, MCP adapter, or hosted
service is included.

- Added a complete documentation entry point and audience-separated guides.
- Documented planned capabilities without presenting them as shipped.
- Added ADR-0001 for the proposed source-of-truth boundary.

## Compatibility and Prerequisites

There is no runtime compatibility matrix. Reading the repository requires Git
and a Markdown-capable editor; no language runtime or package manager is
required.

No installation or upgrade is available. Clone the repository and read

history, and available files. No software test suite exists to run.

sensitive lesson data. Future publication and retrieval behavior must enforce
scope, provenance, review, redaction, correction, revocation, and deletion.
